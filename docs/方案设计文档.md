## 二、活动背景

### 1. 典型场景

| 场景 | 具体表现 |
|------|----------|
| 考前焦虑 | 明天就要考试，觉得自己什么都没准备好，脑子里乱糟糟的，反复翻书却看不进去 |
| 社交困扰 | 和室友发生矛盾后反复回想，觉得是自己的错，开始回避社交，越来越孤独 |
| 自我否定 | 看到同学拿到奖学金，觉得自己什么都不行，陷入"我就是不够好"的循环 |
| 就业压力 | 投了很多简历没有回音，开始怀疑自己的能力和价值，对未来感到恐惧 |
| 情绪积压 | 白天强撑着正常生活，晚上躺在床上却感到莫名的低落和疲惫，不知道向谁倾诉 |

### 2. 核心痛点

| 痛点 | 分析 |
|------|------|
| 情绪难以识别 | 大学生常常说不清自己"到底怎么了"，无法准确命名情绪，导致情绪积压 |
| 负面思维循环 | 灾难化思维（"做不好就完蛋"）、非黑即白（"要么完美要么失败"）等认知偏差难以自我觉察 |
| 缺乏倾诉渠道 | 学校心理咨询预约难、等待时间长，很多学生不愿向身边人袒露脆弱 |
| 缺少科学工具 | 市面心理产品多为测评问卷或冥想音频，缺乏针对大学生场景的个性化情绪干预方案 |

### 3. 心理学视角

| 维度 | 说明 |
|------|------|
| 认知层面 | 大学生正处于自我同一性探索期，容易产生认知偏差和思维陷阱，需要认知重构的工具和引导 |
| 情绪层面 | 学业压力、人际关系、就业焦虑等多重压力叠加，情绪调节能力尚在发展中 |
| 行为层面 | 情绪困扰常表现为拖延、回避、社交退缩等行为模式，需要"微行动"打破恶性循环 |
| 社会支持 | 部分学生缺乏有效的社会支持系统，需要一个随时可用、无评判的倾听者 |

## 三、活动目标

1. **提升情绪觉察力**：帮助大学生准确识别和命名自己的情绪状态，建立"先觉察再应对"的心理习惯

2. **打破负面思维循环**：通过 AI 引导的认知行为疗法（CBT），帮助学生识别 5 种常见思维陷阱，完成从"旧想法"到"新想法"的认知重构

3. **提供可及的心理支持**：打造一个 24 小时可用、零门槛、无评判的 AI 心理健康伙伴，弥补学校心理咨询资源的不足

4. **建立积极心理习惯**：通过感恩日记、正念呼吸、情绪记录等功能，帮助学生培养日常心理健康维护的习惯

## 四、活动方案

### 4.1 方案概述

**晴愈AI** 是一款基于 AI 大模型（DeepSeek）与循证心理学的大学生心理健康 Web 应用。它将认知行为疗法（CBT）、正念减压、积极心理学和情绪聚焦疗法融入产品设计，通过"AI 智能体 + 5 步疗愈流程 + 多维辅助工具"的架构，为大学生提供个性化、科学化的情绪支持。

### 4.2 理论依据

| 理论 | 应用方式 |
|------|----------|
| **情绪ABC理论** | 事件A不直接导致情绪C，不合理信念B是内耗根源。产品核心逻辑：帮助用户识别B（思维陷阱），重构为合理信念 |
| **认知行为疗法(CBT)** | 想法—情绪—行为形成循环，通过 3 轮 AI 对话引导用户完成"识别陷阱 → 分离想法与事实 → 认知重构 + 微行动" |
| **正念减压(MBSR)** | 提供 3 种科学呼吸法（4-7-8 / 方形 / 共振），通过呼吸引导调节自主神经系统，停止思维反刍 |
| **积极心理学** | 感恩日记练习帮助大脑关注积极面，提升主观幸福感 |
| **情绪聚焦疗法(EFT)** | 身体扫描功能引导用户觉察情绪在身体中的感受，建立身心连接 |

### 4.3 核心功能

#### 功能一：AI 智能对话

基于自研智能体架构，AI 助手"晴愈"能够：
- 自主判断用户情绪状态，选择最合适的支持方式
- 调用 10 种工具（身体扫描、呼吸引导、心理测评、文学安慰等）
- 跨会话记忆：记住用户之前分享的事情，体现持续关心
- 危机检测：识别自伤/自杀关键词，立即提供心理援助热线

#### 功能二：5 步情绪疗愈流程

| 步骤 | 名称 | 时长 | 说明 |
|------|------|------|------|
| 步骤1 | 情绪觉察 | 1-2分钟 | 滑动选择情绪强度（1-10），选择情绪类型标签，写下感受 |
| 步骤2 | 身体扫描 | 1-2分钟 | 交互式人体图，点击感到紧张的身体部位（头/眼/喉/胸/腹/手/背/腿） |
| 步骤3 | AI对话引导 | 3-5分钟 | 3轮CBT对话：共情识别陷阱 → 分离想法与事实 → 认知重构+微行动 |
| 步骤4 | 文学安慰 | 1分钟 | AI根据情绪状态创作治愈文字（诗/散文/书信/日记），逐字动画呈现 |
| 步骤5 | 情绪卡片 | 1分钟 | 生成专属疗愈卡片（含情绪类型、思维陷阱、认知重构、微行动建议），可保存为图片 |

#### 功能三：心理测评

- **PHQ-9 抑郁筛查**：9题，评估过去两周抑郁症状频率
- **GAD-7 焦虑筛查**：7题，评估过去两周焦虑症状频率
- 测评后提供分级解读和 AI 个性化分析报告

#### 功能四：正念呼吸

3 种科学呼吸引导模式：
- **4-7-8 呼吸法**：安神助眠，缓解焦虑（吸4秒-屏7秒-呼8秒）
- **方形呼吸**：专注平静，提升注意力（各4秒循环）
- **共振呼吸**：平衡自律神经，身心和谐（各5秒循环）

配合圆形动画随呼吸节奏缩放，直观引导练习。

#### 功能五：感恩日记

每天记录 3 件感恩的小事，培养积极心理习惯。支持历史记录回顾。

#### 功能六：情绪记录仪表盘

- 统计卡片：总记录数、平均情绪降低幅度、最常出现的情绪类型
- Chart.js 趋势图：体验前/后情绪强度变化曲线
- 历史记录列表：每条记录的情绪类型、时间、强度变化、文字描述

### 4.4 使用场景与说明

| 项目 | 说明 |
|------|------|
| 适用场景 | 宿舍、教室、图书馆、考前、赶DDL、情绪低落时 |
| 使用频率 | 每日 1-3 次，每次 3-10 分钟 |
| 使用方式 | 浏览器打开（支持手机/电脑），设置 DeepSeek API Key 即可使用 |
| 数据安全 | 所有数据保存在用户浏览器 localStorage，不上传任何服务器 |
| 注意事项 | 本工具仅供情绪觉察与自我探索参考，不能替代专业心理咨询；检测到危机关键词会立即提供心理援助热线 |

### 4.5 技术实现

| 技术维度 | 说明 |
|----------|------|
| 前端架构 | 提供 HTML 原版（零依赖）和 Next.js 版（现代框架）两个版本 |

## 五、创新亮点

### 1. AI 智能体架构：不只是聊天，而是能"做事"的伙伴

区别于普通 AI 聊天机器人，晴愈AI 采用智能体（Agent）架构——AI 能够自主判断用户需要什么帮助，主动调用工具（身体扫描、呼吸引导、心理测评、生成疗愈卡片等），实现从"被动回答"到"主动支持"的跨越。

### 2. 5 步结构化疗愈流程：从觉察到行动的完整闭环

将循证心理学方法整合为 5 步引导流程（情绪输入 → 身体扫描 → CBT 对话 → 文学安慰 → 情绪卡片），每一步都有明确的心理学依据，用户只需跟随引导即可完成一次完整的认知重构体验。

### 3. 多模态情绪表达：文字、身体、呼吸、创作四维感知

不仅支持文字描述情绪，还通过交互式身体扫描图引导用户觉察情绪的身体感受，通过正念呼吸引导调节生理状态，通过文学创作获得情感共鸣——多维度覆盖情绪感知通道。

### 4. 情绪卡片：可视化的疗愈旅程记录

每完成一次疗愈流程，系统自动生成一张精美的情绪卡片（Canvas 渲染），记录情绪类型、思维陷阱、认知重构过程（旧想法→新想法）、微行动建议和情绪变化。用户可保存为图片分享或留作纪念，形成正向反馈循环。

### 5. 隐私优先 + 零门槛：人人可用的心理健康工具

所有数据保存在用户浏览器本地，不上传任何服务器，消除隐私顾虑。纯前端架构，无需注册登录，设置 API Key 即可使用。提供 HTML 原版（零依赖，双击打开）和 Next.js 现代版两种部署方式，适配不同使用场景。
